h3:Psalms 91
Barekmor - Uyarappettavante Maravil irrikkunnavanum, / Daivathinte nizhalil mahathwa pedunnavanume! 

Barekmor - Njaan aashrayichu irikkunna daivam / ente sharanavum ente sanketha sthalavum ennu / karthhaavine kurichu nee parayuka. 

Enthennaal avan virudhhathhinte keniyil ninnum / vyartha samsaarathhil ninnum ninne veendukollum. 

Avan avante thoovalukal kondu ninne rekshikkum. / Avante chirakukalude keezhil nee maraykka pedum. / Avante sathyam ninte chuttum aayudham aayirikum. 

Nee raathriyile bhayathhil ninnum, / pakal parakkunna asthrathil ninnum / iruttil sancharikkunna vachanathhil ninnum / uchhayil oothunna kaattil ninnum bhayappeduka illa. 

Ninte oru bhaagathu aayirangalum, / ninte valathhu bhagathhu pathinaayirangalum veezhum. 

Ava ninkalekku aduka illa. / Ennalo ninte kannukal kondu nee kaanuka maathram cheyyum. / Dushtanmaarkkku ulla prathiphalathe nee kaanum. 

Enthennaal swantha vaasa sthalam / uyarangalil aakki irikunnu enna / ente sharanam aaya karthavu nee aakunnu. 

Dosham ninnodu adukka illa. / Shiksha ninte vasa sthalathhinu sameepikkayum illa. 

Enthennaal ninte sakala vazhikalilum / ninne kaakkendathinu / avan ninne kurichu avante malakhamaarodu kalpikum.

Ninte kaalil ninaku idarcha bhavikathe irippan / avar thangalude bhujangalin mel ninne vahikum.

Sarpathheyum analiyeyum nee chavittum. / Simhathheyum perumpampineyum nee methikum.

Avan enne anweshichhathu kondu / njaan avane rekshichhu belappeduthhum; / ente naamam arinjathukondu avan enne vilikkum.

Njaan avanodu utharam parayum. / Njerukathhil njaan avanodu koode irrunnu / avane belappeduthi behumaanikkum.

Deerkha aayussu kondu / njaan avane thrupthipeduthhum. / Ente reksha avane njaan kanikkayum cheyyum.
h3:Psalm 121

Ente sahaayam aakashavum bhoomiyum srushhticha / karthhaavinte sannidhiyil ninnu aakunnu.

h3:PRAYER OF MAR SEVERIOS
Uyara pettavante marayil irikkunnavan aaya karthhaave! / ninte anugrahathhinte chirakukalude nizhalin keezhil njangale marachu / njangalude mel anugraham cheyyename 

Sakalavum kelkunnavane! / ninte anugrahathhaal ninte adiyarude apeksha kelkkename 

Mahathwam ulla raajavum njangalude rekshakanum aaya mashiha! / nirappu niranju irikkunna sandhyayum, punnyam ulla raavum njangalku tharename. 

Njangalude kannukal ninkalekku nokkikondu irikunnu, / Njangalude kadangalum papangalum pariharichhu, / ehaparam aaya randu lokangalilum njangalodu karuna cheyyename.

Karthhaave ninte anugrahangal njangale marachu, / ninte krupa njangalude mukhangalil nilkename. / Ninte sleeba dushtanil ninnum avante sainyangalil ninnum njangale kathhukollename.

Njangal jeevanode irikkunna naalukal okkeyum / ninte valathhu kai njangalude mel aavasippikkename. / Ninte nirappu njangalude idayil vazhumaar aakename. / Ninnodu apekshikkunna aathmaakalkku sharanavum rekshayum undakename.

Ninne prasavichha Mariyaaminteyum ninte sakala parisudhhanmaarudeyum praarthanayal, / daivame! njangalude kadangalkku parihaaram undakki, njangalude mel anugraham cheyyename. Amen
